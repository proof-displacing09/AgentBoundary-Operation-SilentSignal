# Design System

Dark-first tokens: bg `#080E1C`, raised `#101A2B`, card `#162238`, border `#27364D`, text `#F3F6FC`, secondary `#A1B0C8`, muted `#798CA8`, positive teal `#68E0D0`, info blue `#79B8F2`, violet `#A5B4FC`, warning amber `#F2B86D`, critical salmon `#F08089`.
Typography: Inter/system-ui stack; ui-monospace for event traces/code. Scale: 12/13/14/16/20/24/30.
Rules: restrained accent use; every status color is paired with a text label (never color-only); radius 8–12px; 4px spacing grid; visible focus rings in info blue; `prefers-reduced-motion` disables non-essential animation; tables are semantic with captions/scope; trust labels (TRUSTED / LOWER-TRUST / UNTRUSTED) are badges with icons + text.
Responsive: ≥1280 full sidebar; ~768 collapsed rail; ~375 top bar + bottom-safe stacked cards, tables scroll horizontally with sticky first column.
Logo: original SVG — a shield outline bisected by a boundary line; wordmark "AgentBoundary" + "Nightwatch Security — Operation SilentSignal" subtitle. No vendor marks.
